# Multilingual PII token classifier — v5.3 (XLM-R large, span head with boundary smoothing)

v5.3 is **v5.2 with a larger encoder**: [XLM-R large](https://huggingface.co/FacebookAI/xlm-roberta-large)
(24 layers, hidden size 1,024, 560M parameters) instead of XLM-R base (12 layers, 278M). The head is v5.2's:
a span head that scores every candidate (start word, end word, entity type) up to 160 tokens long, trained with
boundary smoothing (ε = 0.1, distance 1 word; Zhu & Li, ACL 2022). The training data (`ml_train_v5`), recipe
(3 epochs, encoder LR 2e-5, head LR 1e-4, effective batch 32, seed 42), 8 labels and 12 languages are the same as v5.0–v5.2.

- **The most accurate v5 model** on every benchmark group: held-out test sets, dev sets and English.
- **About 3× slower than the base-size models** on GPU and 3.5× on CPU. For CPU use or large volumes,
  v5.1 / v5.2 are the better trade-off.
- Post-processing: punctuation trim on by default (`"trim_punct": true` in `config.json`).

## Results

### Held-out test sets (strict F1 / coverage)

Scored once, after all v5 choices were made on the dev sets (2026-10-12).

| Set | v5.0 | v5.1 | v5.2 | **v5.3** |
|---|---|---|---|---|
| `ml_struct_test`: unseen sentence structures | 0.948 / 0.985 | 0.945 / 0.966 | 0.948 / 0.977 | **0.970** / **0.987** |
| `ml_wm_test`: wealth-management grid, 12 languages + English–X | 0.949 / **0.996** | 0.960 / 0.983 | 0.956 / 0.989 | **0.969** / 0.994 |
| `ml_wm_known`: same grid, accounts in known institution formats | 0.946 / **0.995** | 0.957 / 0.981 | 0.951 / 0.987 | **0.967** / 0.992 |
| **Mean** | 0.947 / **0.992** | 0.954 / 0.976 | 0.951 / 0.984 | **0.968** / 0.991 |

+0.021 over v5.0 and +0.014 over v5.1 on the held-out mean, with coverage close to v5.0's (0.991 vs 0.992): unlike v5.1 and v5.2, it gains accuracy without giving up coverage.

## Usage

As v5.0. `PIIPredictor` detects the span head (`struct_head.json`) and loads it, so it needs this
repository's code at the `v5.1` tag or later (`src/heads.py`).

```bash
curl -L -o model.zip https://github.com/zackhng/pii-token-classifier/releases/download/v5.3/xlmr-large-pii-ml-v5.3.zip
mkdir -p outputs/xlmr-large-pii-ml-v5.3 && unzip model.zip -d outputs/xlmr-large-pii-ml-v5.3
cd src && python predict.py --model_dir ../outputs/xlmr-large-pii-ml-v5.3 --text "Hi Tan Wei Ming (陈伟明), 已经 transfer SGD 25,000 到 account 123-456789-001"
# -> PERSON 'Tan Wei Ming', PERSON '陈伟明', ACCOUNT '123-456789-001'
```

The zip (1.9 GB) holds `config.json`, `model.safetensors` (encoder, fp32), `struct_head.pt` / `struct_head.json`
(span head) and the tokenizer. SHA-256: `c80882b0f6f7ceb100c99fa003a35f9489406f4fae2b3e8959032b008335c56b`.

## Limitations

- **Speed:** about 3× slower than the base-size models on GPU and 3.5× on CPU (87 s per 100k characters on 6 CPU threads).
- **Single seed.** The margin over the base-size models (+0.014 to +0.021 held-out mean) is well beyond the run-to-run
  differences seen elsewhere in v5. Small per-set differences between the base-size models are not.
- **Korean (Kiii²)** stays at about 0.85 strict for every model: its gold includes brackets that the trim removes
  (see the v5.0 card).
- Everything else in [`v5.md`](v5.md)'s Limitations applies unchanged: synthetic evaluation apart from Kiii², and
  non-commercial training sources.

## Reproduce

```bash
cd src
python train.py --config train_ml.yaml --train_split ml_train_v5 --val_split ml_val_v5 \
  --output_dir outputs/pii-ml-XLMRL-BS-v5data --model_name FacebookAI/xlm-roberta-large \
  --batch_size 16 --grad_accum 2 --grad_ckpt \
  --head span --head_lr 1e-4 --span_loss ce --bs_eps 0.1 --bs_d 1
# ~7.5 h on an RTX 5060 Ti 16 GB; release folder: the trained model + "trim_punct": true in config.json
```

The other v5 experiments (other heads, extra layers, encoder swaps, adapters) are in the README's v5 experiment log.
